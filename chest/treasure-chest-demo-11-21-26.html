treasure-chest：開寶箱的獎勵動畫

一個元件、十四種圖形，用 type 切換：chest 寶箱、trophy 獎盃、gift 禮物盒、gacha 轉蛋機、book 魔法書、almanac 農民曆、receipt 對發票機、tudigong 土地公、news 新聞快報、curtain 拉布幕、shuttle 太空梭、tram 輕軌、calendar 撕日曆、street 街道。越新增的範例放越上面；每個範例的「畫面」與「程式碼」由同一段原始碼產生。單一 treasure-chest.js，CSS 內建，不用 Shadow DOM。

文字顏色（book、almanac）

固定配色 word-colors="auto"

飄出來的文字原本從 9 色裡隨機挑色，同一個詞每次顏色都不同，而且有幾組色相很接近。寫 word-colors="auto" 改用 11 色，第 n 個詞固定用第 n 個顏色，所以下面 11 個詞各自是不同顏色。沒寫 word-colors 就維持原本的隨機配色。詞比顏色多時，顏色會輪流重複。兩本都用 coins="30"，讓 11 個詞都有機會飄出來。

畫面（左：沒寫 word-colors，右：auto。點書打開，開完再點一次重來）

程式碼

自訂顏色 word-colors="key, yellow, pink"

顏色用逗號分隔，可以寫色票名稱或任何 CSS 顏色（例如 #FFA987）。這裡只給三種顏色，六個詞會依序輪流使用：第 1 個詞和第 4 個詞同色，其餘類推。農民曆也適用。

街道（沒有光芒）

街道 type="street"

約 45 度俯視的十字路口，面對鏡頭的轉角是超商，轉角切出一個斜面當作入口，門上有條紋遮陽棚。density（0 到 10，預設 5）同時決定兩件事：每秒有多少顧客走進超商，以及四個車道的車流量；0 就是空街。顧客從兩條人行道走來，走進店裡，過一陣子提著袋子走出來，進出時門會亮起。車子會跟車、遇到紅燈與黃燈停在停止線前排隊，紅綠燈由兩路輪流放行（柱子上兩顆燈，左邊是左右向的車，右邊是前後向的車）。載入時先暖機 8 秒，待機時就已經有車有人，點一下才開始動。有 chest-prize 才會在 3.5 秒後出現文字，街景會持續運作到按 reset。和 shuttle、tram 一樣，預設沒有光芒、星光和噴出物。

畫面（點視窗開始，開完再點一次重來）

程式碼

撕日曆（沒有光芒）

撕日曆 type="calendar"

牆上的日曆一張一張被撕下，每張先從右上角被掀起，再脫手往左下掉，每撕一張整本日曆會在釘子上晃一下，最後停在 date 指定的日期。date 可以寫 2026-11-20、11-20 或 20（沒寫就是今天）；tear 是撕幾張，預設 5，所以第一張是 date 往前推 tear 天，跨月、跨年會自動換成正確的月份與年份。週六、週日的字是紅色。有寫 chest-prize 才會在最後出現文字，沒寫就直接結束。和 shuttle、tram 一樣，預設沒有光芒、星光和噴出物。

畫面（點日曆開始撕，開完再點一次重來）

程式碼

太空梭與輕軌（沒有光芒）

太空梭 type="shuttle"

太空梭沿著傾斜的軌道繞地球飛一圈，繞到地球後面時會被擋住，頭尾慢、中間快，噴射火焰只在飛行時出現，地球一直緩緩自轉。回到起點之後，文字才出現。這兩種圖形沒有金色光芒、星光和噴出物（rays、sparkles、ambient 預設都是關），要的話可以自己用屬性打開。chest-color 是海洋的顏色。

畫面（點視窗發射，開完再點一次重來）

程式碼

輕軌 type="tram"

輕軌車廂從遠方的地平線出發，先沿著軌道直行，再轉彎，朝鏡頭駛來，慢慢煞住停在跟前，文字出現。畫面是真正的透視投影：車廂是一個長方體，每一幀依照在軌道上的位置和方向，重新算出看得到的車頭、側面和車頂，所以轉彎時可以看到側面逐漸轉成正面。chest-color 是車身的色帶顏色。

程式碼

新聞快報與拉布幕

新聞快報 type="news"

老電視頂上的警示燈轉起來，螢幕像映像管一樣從一條白線展開，先出現彩條，再切到轉動的地球，紅色 NEWS 條從左邊滑入，報紙從電視裡噴出。畫面上只有 NEWS 一個英文字。cover-text 是選用的課程標題，會出現在下方字幕條；文字比字幕條長會自動跑馬燈，不寫就是灰色的示意字條。

畫面（點電視打開，開完再點一次重來）

程式碼

拉布幕 type="curtain"

兩側紅布幔往外拉開，聚成窄窄一條，金色匾額彈出，底下堆著元寶，元寶往上噴出。匾額上的字用 cover-text 設定：六個字以內單行，更長會拆成兩行，英文會在空白處拆；不寫就是一個大元寶。

魔法書、農民曆、對發票機、土地公

魔法書 type="book"

封面翻開，四張書頁依序翻過去，翻完時光芒從書脊噴出，文字從書頁飄起來。words 用逗號分隔，沒寫就用預設的「Aa、Bb、學、習、7.0、Good」。cover-text 會印在封面下方。動畫結束後，reveal-targets 指定的元素才會出現。

程式碼

農民曆 type="almanac"

紅皮農民曆翻開，停在今天那頁，大大的印章砰一聲蓋下，蓋下的瞬間光芒噴出。stamp 是印章上的字，一到兩個字最好看；cover-text 預設是「農民曆」，最多五個字，由上往下直排。

對發票機 type="receipt"

機器上的號碼先滾動，由左到右一個一個停下來，發票像印表機一樣一格一格吐出，最後蓋上印章。digits 是八位數字，stamp 是印章字樣。噴出的是飛舞的發票紙片。

土地公 type="tudigong"

福德祠的廟門打開，土地公從裡面笑咪咪探出來，輕輕點頭、鬍子搖晃、拐杖點地，頭頂噴出元寶。土地公是原創的卡通造型：白鬍子、福帽、龍頭拐杖和元寶。coins 決定元寶的數量。

四種搖晃強度

shake 是 0 到 1 的強度，越大搖得越明顯、時間越長，大於 0.4 時還會往上跳；0 不搖晃直接開。舊寫法 true 等同 0.5、false 等同 0。

動畫完結後顯示與刪除元素

點禮物盒。完結時「尚未解鎖」被刪除，兩張解鎖卡出現；按 reset() 全部還原。reveal-targets、remove-targets 用逗號分隔，只寫 id 可以省略 #，也可以寫選擇器。

搭配 link-when：對話播完開寶箱，寶箱開完出現下一課

按對話的「播放」。寶箱當 target 時 do="play"（預設）會開箱；當 source 時 event="done" 等到開箱動畫完成。link-when.js 與 treasure-chest.js 誰先載入都可以。這個範例要連網載入 ielts repo 的 ui-stream 與 link-when，其他範例離線也能用。

屬性預設說明
typechest圖形，共十四種，見上表。
size220圖形寬度（px）。整個舞台約為寬 2.2 倍、高 1.95 倍。
triggerclickclick：點擊開啟；auto：捲動到畫面中自動開啟；none：只用 open() 開啟。
delay300trigger="auto" 時，出現在畫面上之後等幾毫秒再開。
replay關已開啟後再點一次會關回原狀，可以重來。
bgbase舞台背景色。光芒邊緣會過渡到這個顏色，請設成和放置位置相同的底色。
gold、lightyellow、#FFF6C8光芒的主色與最亮的中心色。
chest-color、trim-color依 type主體色與配件色，可寫色票名稱或任何 CSS 顏色；明暗自動計算。street 的 chest-color 是超商的招牌與遮陽棚顏色。
capsule-colorpink轉蛋機掉出的扭蛋顏色。
rays14（shuttle、tram、calendar、street 為 0）光芒條數；0 不畫光芒，只有光暈。shuttle、tram、calendar、street 預設是 0，而且連光暈都沒有。
ray-speed10光芒旋轉速度（度／秒）。
sparkles80（shuttle、tram、calendar、street 為 0）開啟瞬間噴出的星光數量。
coins依 type噴出物數量，0 不噴。噴出物依圖形不同：金幣、彩紙、文字、發票紙片、元寶、報紙。
ambienttrue（shuttle、tram、calendar、street 為 false）開啟後開口持續冒出細小星光；寫 false 關閉。
shake0.5開啟前的搖晃強度，0 到 1；0 直接開啟。
hint依 typetrigger="click" 時圖形下方的提示文字；寫空字串不顯示。
prize-bg、prize-color、prize-sizebase、yellow、1.4rem獎品框的底色、文字色、字級（只寫數字視為 rem）。外框用 gold 的顏色。
words各圖形有預設book、almanac 飄出來的文字，用逗號分隔。
word-colors無（隨機配色）book、almanac 飄出來的文字顏色。auto 使用內建 11 色；也可以自己寫，用逗號分隔，可寫色票名稱或任何 CSS 顏色，例如 red, key, #FFA987。第 n 個詞固定用第 n 個顏色，詞比顏色多時輪流重複；沒寫就維持隨機配色。
stamp宜、中獎almanac、receipt 印章上的字。
cover-text依 typebook 封面下方的字；almanac 封面直排的字（預設農民曆，最多五個字）；news 字幕條上的課程標題（選用，太長會跑馬燈）；curtain 匾額上的字（不寫就是一個元寶）。
date今天calendar 停下來的日期，寫 2026-11-20、11-20 或 20。
tear5calendar 撕幾張（1 到 12），第一張是 date 往前推這麼多天。
density5street 的繁忙程度，0 到 10：決定進出超商的顧客數量，也決定四個車道的車流量；0 是空街。

reveal-targets無動畫完結後要顯示的元素。
remove-targets無動畫完結後要從頁面刪除的元素；reset() 會放回原位。

方法與事件類型說明
open()、play()方法開啟；已經打開時不作用。play() 給 link-when 的 do="play" 使用。
reset()方法關回原狀，可以再開一次；同時還原 reveal-targets 與 remove-targets。
opened、type唯讀屬性動畫是否已完結；目前的圖形名稱。
treasure-chest:open事件開始開啟。detail：{ type }。
treasure-chest:opened事件動畫完結。detail：{ type, revealed, removed }。
treasure-chest:reset事件關回原狀。事件都會冒泡。
