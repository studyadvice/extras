<treasure-chest> 獎勵開啟動畫 v1.3

寶箱先搖晃，箱蓋往後翻開，箱內透出金光，背後射出旋轉的光芒，星光與金幣噴出，獎品從箱口升起，之後光芒持續緩慢旋轉。寶箱是 SVG，光芒、星光、金幣畫在 canvas 上。單一 treasure-chest.js，CSS 內建，不用 Shadow DOM，不需要任何外部資源，離線也能用。光芒以實色漸層過渡到 bg 背景色、以亮度相加的方式疊亮，不使用透明度。

範例 1：點擊開啟，再點一次重來

chest-prize 裡寫獎品內容，可以是任何 HTML。replay 讓已開啟的寶箱再點一次會關上。

Band 7.0 達成！ 
<treasure-chest size="240" replay>
  <chest-prize>Band 7.0 達成！</chest-prize>
</treasure-chest>

<script src="treasure-chest.js"></script>

開箱時間軸
  0 到 0.75 秒   搖晃（越搖越大）
  0.75 秒        箱蓋翻開，箱身先壓扁再彈起
  0.8 秒         光芒展開，星光與金幣噴出
  1.05 秒        獎品從箱口升起
  之後           光芒持續旋轉，箱口不斷冒出細小星光（ambient）

<script src="treasure-chest.js"></script>

寶箱當 B（target）
  do="play"（預設）：開箱
  do="reset"：關回原狀
  do="show"：只顯示；搭配 trigger="auto" 顯示後會自動開箱
寶箱當 A（source）
  event="done"：開箱動畫完成時觸發（treasure-chest:opened）
  event="treasure-chest:open"：一開始開箱就觸發
link-when.js 與 treasure-chest.js 誰先載入都可以，不需要修改 link-when.js

版本對照：v1.0 → v1.1

開箱動畫與所有屬性都沒有改變。

v1.0

/* 寶箱當 A 時，event="done" 不認得寶箱，
   要自己寫完整事件名稱 */

v1.2（11-16-26）：shake 改為 0 到 1 的強度

範例 6：四種搖晃強度並排比較

按「全部開箱」同時播放；單獨點寶箱也可以，開完再點一次會關上。

<treasure-chest shake="0">     ← 不搖晃，直接掀蓋
<treasure-chest shake="0.25">  ← 輕輕晃一下
<treasure-chest>               ← 預設 0.5，與 v1.1 相同
<treasure-chest shake="1">     ← 劇烈搖晃並往上跳

強度 k 影響的項目
  搖晃時間：0.35 + 0.8 × k 秒（0.5 為 0.75 秒）
  最大角度：14 × k 度（0.5 為 7 度）
  晃動次數：隨 k 增加，越強越急
  箱蓋喀喀晃動：越強開得越大
  往上跳：k 大於 0.4 才開始，1 時最明顯
舊寫法照常可用：shake="true" 等同 0.5，shake="false" 等同 0

版本對照：v1.1 → v1.2

沒寫 shake 時，效果與 v1.1 相同。

v1.1

/* 只有開或關 */
shake: a('shake', 'true') !== 'false'

const sh = o.shake ? 0.75 : 0.05;
rot = Math.sin(p * Math.PI * 9) * (2 + p * 5) * (o.shake ? 1 : 0);
lidK = 1 - 0.06 * Math.abs(Math.sin(p * Math.PI * 9)) * p;

v1.2

/* 0 到 1 的強度；true＝0.5、false＝0 */
shake: this._shakeVal(a('shake', '0.5'))

const sh = k > 0 ? 0.35 + 0.8 * k : 0.05;
const w = Math.sin(p * Math.PI * (7 + 4 * k)), env = 0.3 + 0.7 * p;
rot = w * env * 14 * k;
lidK = 1 - 0.12 * k * Math.abs(w) * p;
hop = -Math.abs(w) * p * Math.max(0, k - 0.4) * 14;   /* 新增：往上跳 */

範例 7：type 切換四種圖形

按「全部開啟」同時播放；單獨點也可以，開完再點一次會關上。每種圖形都有自己的開啟動作與噴出物。

<treasure-chest type="chest">   ← 寶箱：搖晃 → 箱蓋往後翻開 → 金幣噴出（與 v1.2 完全相同）
<treasure-chest type="trophy">  ← 獎盃：杯子從底座往上一頂 → 杯口亮起、金幣噴出 → 落回底座，反光每 2.8 秒掃過一次
<treasure-chest type="gift">    ← 禮物盒：盒蓋連蝴蝶結彈飛 → 盒口亮起、彩紙噴出並左右飄落
<treasure-chest type="gacha">   ← 轉蛋機：旋鈕轉兩圈、機內扭蛋跳動 → 扭蛋從出口滾出、飛到正前方放大 → 裂開噴光

各圖形的預設值（沒寫屬性時套用）
  type     chest-color  trim-color   噴出物       hint
  chest    #8A5530      #E8B931      10 枚金幣    點擊打開
  trophy   #3B2A20      #E8B931      8 枚金幣     點擊領獎
  gift     #EF6661      #E3D322      40 片彩紙    點擊拆開
  gacha    #EF6661      #C6C7BD      不噴         點擊轉一次

範例 8：用自己的色票換色

顏色屬性都可以寫色票名稱（key、violet、vanilla…）或色碼，明暗自動計算。

<treasure-chest type="trophy" chest-color="indigo" trim-color="shell" gold="quiet" light="#F2F5FF" prize-color="shell">
<treasure-chest type="gacha"  chest-color="blue"   trim-color="salmon" capsule-color="energetic" gold="energetic">

chest-color    主體色：寶箱木頭、獎盃底座、禮物盒、轉蛋機機身
trim-color     配件色：寶箱金屬、獎盃杯身、緞帶與蝴蝶結、轉蛋機金屬零件；寶箱和獎盃的金幣也用這個顏色
capsule-color  轉蛋機掉出來的那顆扭蛋上半部（預設 pink）；機內的扭蛋用固定的色票彩色
gold、light    光芒主色與最亮的中心色；禮物盒、轉蛋機的金幣用 gold

執行時機：獎品升起、光芒展開之後的「完結」那一刻，與 treasure-chest:opened 同時
寫法：用逗號分隔；只寫 id 可以省略 #，也可以寫選擇器（例如 .tip、#box p）
顯示：拿掉 hidden、清掉 display:none，並往上浮現；刪除：從頁面移除
reset()：顯示過的再藏起來，刪除過的放回原來位置
事件 detail：{ type, revealed: [元素…], removed: [元素…] }

屬性

屬性預設說明
typechest圖形：chest 寶箱、trophy 獎盃、gift 禮物盒、gacha 轉蛋機（v1.3）。
size220圖形寬度（px）。整個舞台約為寬 2.2 倍、高 1.95 倍。
triggerclickclick：點擊開啟；auto：捲動到畫面中自動開啟；none：只用 open() 開啟。
delay300trigger="auto" 時，出現在畫面上之後等幾毫秒再開。
replay關已開啟的寶箱再點一次會關上，可以重來。
bgbase舞台背景色。光芒邊緣會過渡到這個顏色，請設成和放置位置相同的底色。
gold、lightyellow、#FFF6C8光芒的主色與最亮的中心色。
chest-color、trim-color依 type主體色與配件色，可寫色票名稱；明暗自動計算。預設值見範例 7 的表（v1.3 起依 type 不同）。
capsule-colorpink轉蛋機掉出的扭蛋顏色（v1.3）。
rays14光芒條數；0 不畫光芒，只有光暈。
ray-speed10光芒旋轉速度（度／秒）。
sparkles80開箱瞬間噴出的星光數量。
coins依 type噴出物數量：寶箱、獎盃是金幣，禮物盒是彩紙，轉蛋機預設 0；0 不噴。
ambienttrue開啟後箱口持續冒出細小星光；寫 false 關閉。
shake0.5開箱前的搖晃強度，0 到 1，越大搖得越明顯、時間越長，大於 0.4 時還會往上跳；0 直接掀蓋。舊寫法 true 等同 0.5、false 等同 0（v1.2）。
hint依 typetrigger="click" 時圖形下方的提示文字；寫空字串不顯示。
prize-bg、prize-color、prize-sizebase、yellow、1.4rem獎品框的底色、文字色、字級（只寫數字視為 rem）。外框用 gold 的顏色。
reveal-targets無動畫完結後要顯示的元素，逗號分隔；寫 id 可省略 #，也可寫選擇器（v1.3）。
remove-targets無動畫完結後要從頁面刪除的元素，寫法同上；reset() 會放回原位（v1.3）。
<chest-prize>無獎品內容，可以寫任何 HTML。

方法與事件

項目類型說明
open()方法開箱；已經打開時不作用。
play()方法同 open()，給 link-when 的 do="play" 使用（v1.1）。
reset()方法關回原狀，可以再開一次；同時還原 reveal-targets 與 remove-targets（v1.3）。
type唯讀屬性目前的圖形名稱（v1.3）。
opened唯讀屬性動畫是否已完成、寶箱已經打開。
treasure-chest:open事件開始開箱。
treasure-chest:opened事件動畫完結（寶箱約 2 秒、轉蛋機約 3.4 秒）。detail 有 type、revealed、removed（v1.3）。
treasure-chest:reset事件關回原狀。都會冒泡。
link-when串接event="done" 對應 treasure-chest:opened；當 target 時 do="play" 開箱（v1.1）。
