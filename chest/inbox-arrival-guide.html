<inbox-arrival> 收件匣收到新郵件

模擬郵件程式收到新信：鈴鐺搖晃、未讀數加一，新郵件從列表頂端滑入並亮起；可以加通知卡，或讓游標移過去點開新郵件、展開閱讀窗格。單一檔案 inbox-arrival.js，CSS 內建，不使用 Shadow DOM，不需要任何外部資源，離線也能用。顏色一律實色，不使用透明度。畫面是自創的通用郵件程式，不模仿任何真實產品。範例頁：inbox-arrival-demo-11-27-26.html。

快速開始

<inbox-arrival replay>
  <inbox-mail from="王老師" subject="本週口說作業" time="昨天" unread>請在週五前完成 Part 1 錄音。</inbox-mail>
  <inbox-mail from="教務處" subject="期中考時間公告" time="11月25日">考試地點在 B203。</inbox-mail>
  <inbox-mail new from="IELTS 成績中心" subject="你的成績已公布">恭喜！口說 7.0，寫作 6.5。</inbox-mail>
</inbox-arrival>

既有郵件與新郵件

收件匣裡的每一封信都寫成一個 <inbox-mail>，用有沒有 new 區分：

  • 既有郵件（沒有 new）：一開始就在列表上，依原始碼順序由上往下排。可以加 unread 顯示成未讀、star 加星號、attach 顯示附件圖示。
  • 新郵件（有 new）：播放時依原始碼順序一封一封抵達，每一封都插到最上面，所以最後抵達的會排在第一列。新郵件一律是未讀，time 沒寫時顯示「剛剛」。
  • 一封新郵件都沒有時，主控台會提醒，並改用一封預設的「你有一封新郵件」。

未讀數

鈴鐺徽章與左側「收件匣」旁的數字一起變動。起始值是既有郵件裡 unread 的封數；想模擬畫面外還有很多舊信，可以在 <inbox-arrival> 寫 unread="12" 直接指定。每抵達一封加一，打開一封未讀信件減一，數字為 0 時徽章隱藏。

骨架列

既有郵件少的時候，列表下方會用灰色骨架列補滿，看起來像還有更多信件。預設 filler="auto" 補到既有郵件加骨架列共 8 列；寫數字指定列數，寫 0 不補。骨架列不能點。

想自動補、但不要補太多，可以加 filler-max。例如既有郵件 2 封時，auto 原本會補 6 列，加上 filler-max="2" 就只補 2 列。filler 寫數字時不看 filler-max。列表區大約看得到 7 列半，超過的會被裁掉；新信抵達時也會把下面的列往下推出畫面。

左側欄寬度

sidebar 有四種寬度。畫面固定 960 寬，側欄越寬，右邊的列表與閱讀窗格就越窄。

  • narrow：72px，只剩圖示；「撰寫」變成圓形筆圖示，收件匣的未讀數變成圖示右上角的小圓點，左上角只留標誌圖示。適合單字表這類需要較寬內容區的用途。
  • medium：200px，預設。
  • wide：260px，適合比較長的資料夾名稱。
  • none：不顯示側欄，列表與閱讀窗格使用整個寬度。

收完信後閱讀

動畫完結後，點列表上任何一封信（既有或新的）都會在右側閱讀窗格打開，並標為已讀；窗格右上角的「關閉」可以收起。

動畫流程

待機
顯示既有郵件與骨架列；trigger="click" 時下方出現提示文字。
每封新信
鈴鐺搖晃 → 0.2 秒後新信從頂端滑入、原有信件往下推，那一行先亮成強調色再漸變回未讀樣式 → 未讀數加一；有 toast 時右上角滑出通知卡，約 2.8 秒後收回。
多封新信
每封間隔 interval 毫秒。
打開新信
有 cursor 時，游標從右下角移到最後一封新信上按一下，出現點擊波紋；只有 open-mail 時，那一行輕壓一下。接著展開閱讀窗格。
完結
沒有打開信件：最後一封新信亮起漸變結束時。有打開信件：閱讀窗格展開之後。此時執行 reveal-targets、remove-targets，link-when 的 event="done" 也在這一刻觸發。

inbox-arrival 屬性

屬性預設說明
triggerclickclick：點畫面開始；auto：捲動到畫面中自動開始；none：只由 link-when 或程式啟動。

cursor關顯示游標移過去點開新信的動作。寫了 cursor 就會打開信件，不必再加 open-mail。
replay關完結後下方出現重播按鈕，點了回到待機並重新播放。

inbox-mail 屬性

屬性預設說明
new無有寫就是新郵件，播放時才抵達；沒寫就是既有郵件。
from寄件人寄件人名稱，頭像取第一個字。
email無寄件人信箱，只在閱讀窗格顯示。
subject（無主旨）主旨。
time新郵件「剛剛」右側時間，任何文字都可以，例如「昨天」、「11月25日」、「上午 9:12」。
unread無既有郵件顯示成未讀（粗體、左側色條），並算進起始未讀數。新郵件一律未讀。
star無加上星號。
attach無顯示附件圖示；寫檔名（例如 attach="exam.pdf"）時，閱讀窗格會顯示那個檔名，只寫 attach 顯示「附件」。
color依寄件人頭像顏色；沒寫時依寄件人名稱自動挑色，同一個寄件人顏色固定。

標籤之間的內容就是信件內文，可以寫任何 HTML（例如多個 <p>）。列表上顯示的是去掉標籤後的純文字摘要，閱讀窗格顯示完整內容。

信件內放按鈕與 ui-btn

內文可以放一般按鈕、連結，也可以放 studyadvice/open 的 <ui-btn>（ui-plus.js）。兩支檔案誰先載入都可以。

<inbox-mail new from="王老師" subject="Part 2 題卡與提示">
  <p>這週的題卡：Describe a place you would like to visit.</p>
  <ui-btn theme="yellow" chevron label-open="收起提示">看提示</ui-btn>
  <div hidden>先說地點和原因，再描述你想做的事。</div>
  <ui-btn theme="key" target="open-area" remove-targets="lock-area">解鎖練習區</ui-btn>
</inbox-mail>

<script src="https://cdn.jsdelivr.net/gh/studyadvice/open@main/ui-plus.js"></script>
<script src="inbox-arrival.js"></script>
  • 開信時，內文是從 <inbox-mail> 整批搬進閱讀窗格，不是複製；關信或改看別封時再搬回去。所以頁面上永遠只有一份內容，id 不會重複，按鈕的 target 寫在信裡或信外都可以。
  • 同一場播放中，關掉信件再打開，按鈕會維持上次的狀態，例如展開過的提示仍然是展開的。
  • 重播或呼叫 reset() 時，信件裡的 ui-btn 會一起回到初始狀態：展開過的收回、remove-targets 刪掉的元素放回原位。這需要新版 ui-plus.js（有 UiBtn.reset()）；沒載入 ui-plus 時自動略過。
  • 列表的灰色摘要只取文字，按鈕上的字不會出現在摘要裡。
  • 畫面是整張等比縮放，按鈕也會跟著縮放，大小請以 960 寬的畫面為準。

屬性預設說明
bgbase頂列與左側欄的底色。
panelbg-alternative信件列表與閱讀窗格的底色。
accentkey強調色：未讀色條、新信亮起、撰寫按鈕、通知卡外框、點擊波紋、提示文字。

可以寫色票名稱（例如 key、bg-alternative、playful），也可以寫 #RRGGBB 色碼。因為深淺是用混色算出來的，請不要寫 rgb() 或顏色英文名稱。

完結後顯示或刪除元素

<inbox-arrival open-mail reveal-targets="rv-a,rv-b" remove-targets="rv-lock">
  <inbox-mail new from="課程助教" subject="下一課的教材已開放">可以開始準備了。</inbox-mail>
</inbox-arrival>

<div id="rv-lock">尚未解鎖：收完信後才能看到教材。</div>
<div id="rv-a" hidden>教材 1：Part 2 口說題卡</div>
<div id="rv-b" style="display:none">教材 2：本課語塊表下載</div>
  • 寫法：用逗號分隔；只寫 id 可以省略 #，也可以寫選擇器，例如 .tip、#box p。找不到的項目會在主控台提醒。
  • 顯示：拿掉 hidden、bp-hidden、d-none，清掉 display:none，並往上浮現；CSS 本身設為 display:none 的元素會改成 display:block。
  • 刪除：從頁面移除。
  • 重播時，顯示過的再藏起來，刪除過的放回原來的位置。信件裡 ui-btn 影響過的元素也會一起還原。
  • 規則和 treasure-chest、cycling-sprint 相同。

搭配 link-when

studyadvice/open 的 <link-when> 可以直接串接，不需要修改 link-when.js；兩個檔案誰先載入都可以。

<!-- 對話播完 → 收件匣出現並開始收信（do 預設 play） -->
<link-when source="#lesson" target="#inbox" delay="388" enter="pop"></link-when>

<!-- 收件匣完結（event="done"）→ 顯示下一步 -->
<link-when source="#inbox" target="#next" do="show" delay="300" enter="slide-up"></link-when>

<inbox-arrival id="inbox" hidden trigger="none" open-mail> … </inbox-arrival>

<script src="https://cdn.jsdelivr.net/gh/studyadvice/open@main/lw/link-when.js"></script>
<script src="inbox-arrival.js"></script>
  • 收件匣當 target：do="play"（預設）開始播放，do="reset" 回到待機，do="show" 只顯示（搭配 trigger="auto"，顯示後會自動開始）。
  • 收件匣當 source：event="done" 等到動畫完結才觸發下一步。
  • 當 target 而且不希望學生先點，請寫 trigger="none"，再用 hidden 先藏起來。
