<cycling-sprint> 單車衝刺動畫 v1.0

選手起步、加速、站起來衝刺，撞斷終點彩帶，彩紙噴出，舉手歡呼，最後彈出成績。背景有視差捲動的遠山、近山、夕陽與看台人群，可加 0 到 2 位對手。全部畫在 canvas 上，單一 cycling-sprint.js，CSS 內建，不用 Shadow DOM，不需要任何外部資源，離線也能用（本頁的 Bootstrap 只用在下方的訊息框）。顏色全部是實色，不使用透明度。

加上 replay，播完再點一次會回到起跑線。

  <sprint-result>Band 7.0 衝線！</sprint-result>
</cycling-sprint>

<script src="cycling-sprint.js"></script>

時間軸（duration 預設 5200 毫秒）
  0 到 56%   起步、加速，背景視差捲動
  56 到 80%  站起來衝刺，出現速度線，把對手甩在後面
  80%        前輪撞斷彩帶，彩紙噴出
  80 到 100% 舉手歡呼、滑行、停下，成績彈出

範例 4：seek() 拖曳預覽任何一個瞬間

trigger="none"：不會自己播放，用滑桿或 play() 控制。設計配色時很好用。

金牌 
<cycling-sprint id="c4" trigger="none" jersey="green" shorts="gray">…</cycling-sprint>

c4.seek(0.7);    // 畫出 70% 那一刻（0 到 1），可連續呼叫
c4.play();       // 從頭播放
c4.reset();      // 回到起跑線

屬性總覽

屬性預設說明
size640畫面寬度（px），高度是寬度的 0.55 倍，最小 240、最大 1600。
triggerclickclick 點擊開始；auto 捲動到畫面中自動開始；none 只用 play()。
delay300auto 時，出現在畫面上之後等幾毫秒再開始。
duration5200整段動畫的毫秒數（2000 到 20000）。
rivals2對手人數，0 到 2。
replay關播完再點一次會回到起跑線。
standingtrue衝刺時選手是否站起來；寫 false 全程坐著。
jersey、shorts、helmet-color、bike-color、skin-coloryellow、indigo、vanilla、red、salmon選手的車衣、車褲、安全帽、車架、膚色。
sky-top、sky-bottombase、bg-alternative天空由上到下的漸層（兩端都是實色）。
tape-colorpink終點彩帶顏色。
gate-textFINISH終點拱門橫幅上的文字。
crowdtrue是否畫看台人群；終點附近比較密，過線後會舉手歡呼。
confetti80過線時噴出的彩紙數量，0 不噴。
hint點擊衝刺trigger="click" 時畫面下方的提示文字；寫空字串不顯示。
radius14畫面圓角（px）。
accentyellow成績框的外框色。
prize-bg、prize-color、prize-sizebase、yellow、1.4rem成績框的底色、文字色、字級（只寫數字視為 rem）。
reveal-targets、remove-targets無動畫結束後要顯示、要刪除的元素，用逗號分隔，寫 id 可省略 #。

顏色屬性可以寫色票名稱（yellow、key、playful…）或任何 CSS 顏色。方法：play()、reset()、seek(0 到 1)、唯讀 finished。事件：cycling-sprint:start、:finish、:finished、:reset，都會冒泡。支援 <link-when event="done">（對應 :finished）。
